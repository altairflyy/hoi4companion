01 · DA DARE ALLA TUA IA

Prompt completo per creare la guida

Apri una conversazione con l’IA che preferisci, incolla questo prompt e aggiungi il link YouTube/web oppure gli allegati. Chiedile di restituire il file indicato dal prompt. Puoi partire subito, senza acquisire fonti nel programma.

Leggi il prompt

Il catalogo aiuta l’IA a scegliere gli ID della tua installazione. Puoi ometterlo: le corrispondenze dubbie verranno segnalate nell’anteprima.

Prepara il video da allegare all’IA

Risoluzione originale fino a 1080p · 15 FPS · H.265 · audio mono 64 kbps. Accelerazione hardware verificata quando disponibile; altrimenti x265 CRF 22. Parti entro 150 MB, con 15 secondi in comune. La qualità hardware usa parametri propri: il valore 22 non equivale esattamente a CRF 22.

02 · RISPOSTA DELL’IA

Carica il file restituito dall’IA

Il file contiene istruzioni e fonti. I checksum vengono calcolati automaticamente dal programma. Puoi anche incollare l’intero JSON nell’editor qui sotto.

Opzioni aggiuntive: acquisizione nel programma e API IA

Acquisizione facoltativa

Nessuna fonte

YouTube: descrizione e sottotitoli disponibili, senza login né download del video. Web: testo HTML statico. I fotogrammi e le immagini non sono analizzati.

API IA facoltativa

Il pacchetto contiene istruzioni, fonti e ID: forniscilo all’IA che usi e chiedile di restituire soltanto il JSON della guida. Nessun dato della partita è incluso. Il pulsante API invia queste fonti a OpenAI e può consumare credito API.

03 · REVISIONE

Anteprima modificabile

Modifica titoli e corrispondenze nelle schede. Per le costruzioni apri «Correggi costruzione»: puoi scegliere regione, edificio, quantità e istruzione senza scrivere JSON. L’editor JSON resta disponibile per gli altri parametri. Ogni modifica richiede una nuova validazione.

Nessuna bozza validata.
