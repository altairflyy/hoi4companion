01 · DA DARE ALLA TUA IA

Prompt completo per creare la guida

Apri una conversazione con l’IA che preferisci, incolla questo prompt e aggiungi il link YouTube/web oppure gli allegati. Chiedile di restituire il file indicato dal prompt. Puoi partire subito, senza acquisire fonti nel programma.

Leggi il prompt

I file per l’IA conservano ID, nomi inglesi, relazioni e solo alias distinti attestati nei riferimenti inglesi del gioco. Traduzioni e alias non verificati restano nel programma.

Le sezioni non si sovrappongono: focus; ricerche; produzione ed equipaggiamenti; costruzioni e regioni; progetti speciali; politica, personaggi e decisioni; eventi e risposte. Allega soltanto quelle necessarie alla fase di analisi. L’albero selezionato filtra i focus e, quando la nazione è nota, esclude eventi, risposte, leggi, idee, consiglieri e decisioni con condizioni nazionali incompatibili. Per politica e decisioni si assume che la nazione selezionata sia anche quella d’origine; vengono rispettati i vincoli della categoria e dell’incarico. Le voci condivise e incerte restano incluse: non è una previsione completa della partita. Nomi e prefissi degli ID non sono prove della nazione. Le altre sezioni restano globali. Eventi e risposte restano collegati tramite event_id. Deseleziona il filtro eventi per includere anche quelli a risposta unica. Senza catalogo, gli ID incerti restano da risolvere.

Catalogo completo, in alternativa alle sezioni

Contiene tutte le categorie, compresi gli eventi a risposta unica. Non allegarlo insieme alle sezioni: duplicherebbe le stesse voci.

Prepara il video da allegare all’IA

Risoluzione originale fino a 1080p · 15 FPS · H.265 · audio mono 64 kbps. Confronto GPU/CPU su campioni reali: preferenza hardware se il file è entro il 25% dal più piccolo; altrimenti x265 CRF 22. Master compatibili riutilizzati senza ricodifica. Parti da 5 minuti, con 10 secondi in comune; ultima parte più breve. Ogni file resta entro 150 MB: se necessario le parti vengono accorciate. Il valore di qualità hardware 22 non equivale esattamente a CRF 22. Il sorgente per i fotogrammi viene conservato; le preparazioni precedenti dello stesso video vengono ripulite dopo il completamento della nuova.

02 · RISPOSTA DELL’IA

Carica il file restituito dall’IA

Il nuovo prompt usa azioni semplici: costruire, ricercare, nominare e scegliere risposte. Il programma le converte nella guida utilizzata dal runtime. I file precedenti restano compatibili. Se manca un campo, il file resta nell’editor per correggerlo. Puoi anche incollare l’intero JSON qui sotto.

Opzioni aggiuntive: acquisizione nel programma e API IA

Acquisizione facoltativa

Nessuna fonte

YouTube: descrizione e sottotitoli disponibili, senza login né download del video. Web: testo HTML statico. I fotogrammi e le immagini non sono analizzati.

API IA facoltativa

Il pacchetto contiene istruzioni, fonti e ID pertinenti al testo acquisito; per un evento incluso conserva evento e relative risposte. Se le scelte si vedono soltanto nel video, usa la sezione Eventi e risposte per le associazioni mancanti. Evita di allegare cataloghi già contenuti nel pacchetto. Nessun dato della partita è incluso. Il pulsante API invia queste fonti a OpenAI e può consumare credito API.

03 · REVISIONE

Anteprima modificabile

Modifica titoli e corrispondenze nelle schede. Per le costruzioni apri «Correggi costruzione»: puoi scegliere regione, edificio, quantità e istruzione senza scrivere JSON. L’editor JSON resta disponibile per gli altri parametri. Ogni modifica richiede una nuova validazione.
