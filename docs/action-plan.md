# Reading the Actions column

Word collections retain the original Actions block number and source key. Each
block can contain several monitored actions and method notes. Splitting a block
does not renumber later blocks or change campaign checks. Older Word imports
recover these positions from their source evidence in memory; imported files are
not rewritten. Missing or conflicting source evidence remains unplaced.

The walkthrough shows each block in source order, with its operations in reading
order. Explicit dependencies take precedence over this display order. Research
and national-focus columns remain independent priority lists in their trees;
sharing a table row never establishes a dependency between the three columns.

## Operational instructions

- Production shows each product, requested versus assigned factory quota, and
  remaining-capacity instructions. A referenced design is retained; generic
  equipment names do not introduce a design-name constraint.
- Construction shows the building, destination and additional/total quantity
  when specified. Queue evidence starts an action; completion still requires the
  declared target/baseline criterion. Cancelling a queue does not complete it.
- Projects, laws, appointments and event responses use their resolved targets.
  Costs, role/facility requirements and runtime sequencing are preserved.
- Method notes stay compact, without automatic completion claims. The original
  instruction and evidence are available in an expandable detail.
- Reading aids reuse the versioned abbreviation vocabulary. Ambiguous codes
  such as SD or unqualified experience currencies are not expanded by guessing.

## Explicit compound commands

An instruction such as `Start special project: Example Project, then War Economy
(150PP), then Limited Conscription (150PP)` can become three operations only if
all targets resolve uniquely through the existing catalog. The first dependency
uses `depends_on_started`; the second uses `depends_on`. `Complete project:`
instead requires completion. An ampersand separates complete supported commands
without inventing a completion barrier. A partially recognized compound sentence
remains a reminder; costs and conditions are never borrowed from its neighbour.

The native HUD still consumes the same runtime decisions as the application.
Per-action messages distinguish a supported target from an unresolved identity,
a resource/dependency wait, and an unsupported control. A supported target is
not proof that a border is currently visible. Current HUD diagnostics are shown
only for a matching guide and qualified live context. Political actions retain
their order; an expensive first action is not replaced with a cheaper later one.

There are no new authoring fields to supply, AI calls, memory writes, clicks or
polling loops. Structural `action.params.source_action` metadata is generated by
the Word importer and does not alter runtime admission. The optional glossary is
an enrichment for reading, not a condition or execution record.

## Validation and limits (3 November 2026)

The follow-up content/identity audit separates the local 61-guide archive into
47 ready guides and 14 unavailable with the current DLC configuration. All six
real import failures in the ready-content group were corrected through scoped
compound spelling, singular/plural handling and declared-branch context. There
are zero remaining identity errors in the 47 available guides. The 14 DLC cases
are not errors or association-review tasks: their guide options remain grey and
disabled. Imported guide files were not rewritten.

The comparison produced 29 more structured operations and 17 additional start
predicates. These are importer results, not claims of live game verification.
The apparent reminder count increases because secondary method notes are kept
when an action is separated from its original sentence.

Python: 1,114 tests passed. JavaScript: 420 tests passed. The actual Hungarian
walkthrough was inspected in an isolated Edge browser at desktop and narrow
widths. Game/HUD alignment was not verified in this task: HOI4 was closed.
Construction, broad army manoeuvres, trade/setup methods and other unsupported
native controls still require following the instructions in the game. There is
no claim that every source sentence can now be automatically monitored.

The importer was also exercised in a real isolated browser with two unmodified
Word-derived drafts: a DLC-blocked Brazilian guide showed its Trial of Allegiance
requirement and zero review issues; the Polish Romanov draft passed validation
with zero unresolved identities and one reported route reconstruction. Neither
draft was installed or selected as the active campaign guide during this check.
