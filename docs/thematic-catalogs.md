# Thematic catalogs for external AI

Exports split non-overlapping topics into focus, research, production, construction, projects, politics, events, and other. Each entity appears in its topic, reducing irrelevant input for source analysis.

English identity references remain primary. Exported aliases contain only meaningful English alternatives, not mere translations. Localization stays local using localization_policy:local_lookup. Event options retain event_id; multiple-choice filtering and selected-country filtering affect both counts and exported data.

Country filters are conservative and static across nations. Shared/uncertain entities remain, and absence does not prove impossibility. Political categories, characters, and decisions use applicable national context rather than a hardcoded personal mod list.

Detailed historical implementation notes and recorded evidence are preserved in the
[Italian reference](it/thematic-catalogs.md). Those records retain their original dates and
verification limits; they are not a claim that every check was rerun for this translation.
