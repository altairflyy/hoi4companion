# Read-only source recovery

Known malformed or tool-incompatible source constructs may be adapted in memory when an exact content hash and narrowly verified correction apply. The original installation is never edited.

Distinguish recovered files, excluded files, unresolved parser disagreements, and successful analysis. Recovery does not prove semantic equivalence for arbitrary future files. Retain an audit record so diagnostics can be investigated later without weakening parser or identity checks.

Detailed historical implementation notes and recorded evidence are preserved in the
[Italian reference](it/source-recovery.md). Those records retain their original dates and
verification limits; they are not a claim that every check was rerun for this translation.
