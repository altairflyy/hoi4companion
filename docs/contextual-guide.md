# Contextual guide resolution

The resolver uses entity kind, selected country/tree, guide route, dependencies, DLC availability, and explicit evidence to disambiguate candidates. Similar names are not enough to choose a branch or infer that an action occurred.

Reusable indexes reduce repeated catalog scans. Geography resolves supported city/province/state relationships locally. An ambiguous place or incompatible context remains reviewable rather than selecting the first candidate.

Detailed historical implementation notes and recorded evidence are preserved in the
[Italian reference](it/contextual-guide.md). Those records retain their original dates and
verification limits; they are not a claim that every check was rerun for this translation.
