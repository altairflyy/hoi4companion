# Technology visual assets

Resolve technology graphics from installed sprite definitions and assets, including national variants and DLC-dependent definitions. Convert/cache assets locally for the web UI without redistributing proprietary game files.

Image availability and entity identity are separate. Missing sprites must not change research recommendations or choose an unrelated technology. Preserve supported animation/frame behavior and distinguish extraction errors from layout problems.

Detailed historical implementation notes and recorded evidence are preserved in the
[Italian reference](it/tech-visual-assets.md). Those records retain their original dates and
verification limits; they are not a claim that every check was rerun for this translation.
