# Technology folder layout

Layout comes from game folder definitions, GUI coordinates, direction, node dimensions, and connector composition. Horizontal and vertical progressions have different geometry; do not expand native coordinates into a generic grid.

Cornered frame sprites enclose regions rather than tile into a grid. Unmapped data remains accessible as catalog information without being falsely placed on the game sheet. Track exceptional or unsupported layouts explicitly.

Detailed historical implementation notes and recorded evidence are preserved in the
[Italian reference](it/technology-layout.md). Those records retain their original dates and
verification limits; they are not a claim that every check was rerun for this translation.
