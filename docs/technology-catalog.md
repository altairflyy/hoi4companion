# Technology catalog

Technology definitions expose IDs, English references, installed localized labels, folder membership, paths, prerequisites, years, unlocks, and relevant metadata. One technology can participate in multiple visual or upgrade relationships.

Resolve the next upgrade within the correct branch using a certain baseline. Avoid arbitrary first-name matches or selecting an incompatible DLC variant. Catalog identity does not establish that a technology is currently researched or researchable.

Detailed historical implementation notes and recorded evidence are preserved in the
[Italian reference](it/technology-catalog.md). Those records retain their original dates and
verification limits; they are not a claim that every check was rerun for this translation.
