# National focus visual fidelity

The renderer uses installed focus definitions, coordinates, relative anchors, GUI spacing, sprites, and connector textures. The guide projection highlights the intended entity without replacing the game-derived layout.

Visual improvements should target measured differences, including legacy trees and exceptional connector compositions. Keep unresolved GUI cases explicit. Screenshot geometry evidence applies to the measured configuration; it is not a guarantee for every mod, zoom, resolution, or game version.

Detailed historical implementation notes and recorded evidence are preserved in the
[Italian reference](it/focus-fidelity.md). Those records retain their original dates and
verification limits; they are not a claim that every check was rerun for this translation.
