# Intelligence monitoring

Agency creation, upgrades, and intelligence operations are different action types. A started agency is not a completed upgrade, and an operation name alone does not prove execution.

Use qualified live observations only for fields supported by the reader. Keep unobservable operation details explicit rather than adding universal manual confirmations or inferring completion from unrelated state changes.

Detailed historical implementation notes and recorded evidence are preserved in the
[Italian reference](it/intelligence-live.md). Those records retain their original dates and
verification limits; they are not a claim that every check was rerun for this translation.
